# Projects

One folder per CLI tool. Each folder is self-contained — its own source, its own
dependencies, and its own `README.md` describing purpose, stack, install, and usage.

Folder names are lowercase kebab-case (e.g. `disk-report`, `wifi-switch`).

## Tools

- [`hevy`](hevy/) — sync Hevy workouts into `Træning.xlsx`.
- [`lidaction`](lidaction/) — set what closing the laptop lid does (AC and DC).
- [`study`](study/) — open the Literature repo in VS Code.
